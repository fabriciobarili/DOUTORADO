Capítulo 6 — Redes Neurais Feedforward (MLPs)

Máquinas de aproximação de funções: como camadas de transformações simples compõem representações cada vez mais abstratas — sem loops, sem memória, só matemática em cadeia.

📄 60 páginas 📌 Seções 6.1 – 6.6 🎯 Fundamento de todo o DL moderno
RESUMO

O capítulo em 5 pontos

resumointuiçãooverview

Leitura de 3 minutos

  1. O que é uma rede feedforward (MLP)? É uma "máquina de transformar dados" — ela pega uma entrada (ex: uma imagem, uma frase), passa por várias camadas de transformações matemáticas e produz uma saída (ex: "isso é um gato"). Não há ciclos, não há memória — a informação flui só em uma direção: da entrada para a saída.
  2. Por que precisamos de não-linearidade? Redes lineares não conseguem aprender coisas simples como o "ou exclusivo" (XOR). A solução é adicionar uma função de ativação não-linear em cada neurônio — a mais popular hoje é o ReLU, que simplesmente corta valores negativos para zero.
  3. Como a rede aprende? Medindo o quanto errou (função de custo/perda), calculando em qual direção cada peso precisa ser ajustado (gradiente) e atualizando todos os pesos um pouquinho nessa direção (gradiente descendente). Esse ciclo se repete milhares de vezes.
  4. Qual é a arquitetura certa? Redes profundas (muitas camadas) são muito mais eficientes que redes largas (poucos neurônios por camada). Teoricamente uma única camada oculta poderia aproximar qualquer função — mas na prática precisaria de um número absurdo de neurônios. Profundidade é o segredo.
  5. O que é retropropagação? É o algoritmo que calcula os gradientes de forma eficiente usando a regra da cadeia do cálculo diferencial. Funciona de trás para frente: começa no erro da saída e vai distribuindo a culpa para cada peso da rede. Sem ele, treinar redes profundas seria inviável.

Mapa Conceitual

Analogia

Pense numa linha de montagem industrial. Cada estação (camada) pega o material recebido, aplica uma transformação especializada, e passa o resultado para a próxima. A peça entra bruta de um lado e sai acabada do outro. A rede feedforward é essa linha de montagem — mas em vez de peças físicas, ela transforma representações matemáticas dos dados.

6.1

Exemplo Motivador: Aprendendo XOR

XORnão-linearidademotivaçãointuição

O XOR (ou exclusivo) é o problema mais simples que uma rede linear não consegue resolver — e é justamente por isso que ele é o exemplo perfeito para motivar o uso de não-linearidade.

Intuição — O que é XOR?

XOR diz: "retorna 1 se os inputs são diferentes, e 0 se são iguais." É como a pergunta "vocês concordam?" — se dois juízes dão votos iguais (ambos sim ou ambos não), o resultado é 0 (consenso). Se dão votos diferentes, o resultado é 1 (discordância).

x₁x₂XOR (saída desejada)
000
011
101
110

Por que uma rede linear falha?

XORgeometriaseparabilidade linear

A solução da rede

XORfórmulaReLUpesos

O livro apresenta uma rede com uma camada oculta de 2 neurônios e ativação ReLU que resolve o XOR exatamente:

f(x) = w⊤ · max{0, Wx + c} + b W = [[1, 1], c = [ 0] w = [ 1] b = 0 [1, 1]] [-1] [-2]
Lendo a fórmula:
W — matriz de pesos da camada oculta (2×2)
c — viés (bias) da camada oculta
max{0, z} — função ReLU (corta o que for negativo)
w — pesos da camada de saída
b — viés da camada de saída
Verificação numérica (input = [0, 1])

1. Pré-ativação: z = W·[0,1] + c = [0+1+0, 0+1−1] = [1, 0]

2. Após ReLU: h = max{0, z} = [1, 0]

3. Saída: ŷ = w·h + b = 1·1 + (−2)·0 + 0 = 1 ✓

XOR(0,1) = 1. Certo!

O que a camada oculta faz?

Ela reescreve o espaço dos dados. Os dois neurônios ocultos detectam padrões diferentes: um detecta "pelo menos um está aceso", outro detecta "os dois estão acesos". A camada de saída combina esses detectores: "aceso, mas não os dois" → isso é XOR.

É como contratar dois analistas especializados e depois um gerente que combina os relatórios deles.

6.2

Aprendizado Baseado em Gradiente

gradientecustoaprendizadoSGD
Intuição — Gradiente como bússola

Imagine que você está numa montanha com nevoeiro e quer chegar ao vale mais baixo. Você não pode ver longe, mas pode sentir a inclinação do chão sob seus pés. Você dá um passo na direção que desce mais. Repete. Isso é o gradiente descendente: o gradiente diz qual direção é "subida", e você vai na direção oposta.

Na rede neural, a "altitude" é o erro da rede. Os "pés" são os pesos. A cada iteração, ajustamos os pesos um pouquinho na direção que reduz o erro.

Funções de Custo — Máxima Verossimilhança

custoverossimilhançaentropia cruzada

A maioria das funções de custo modernas vem do princípio de máxima verossimilhança: queremos encontrar os parâmetros θ que tornam os dados observados o mais prováveis possível.

J(θ) = -E_{x,y~p_dados} [ log p_modelo(y | x; θ) ]
J(θ) — custo total (queremos minimizá-lo)
E[...] — valor esperado sobre os dados de treino
log p_modelo(y|x; θ) — log-probabilidade de acertar y dado x
θ — todos os parâmetros da rede (pesos e vieses)
Por que entropia cruzada, não MSE?

O erro quadrático médio (MSE) tem um problema: quando a sigmoide está saturada (produzindo valores muito próximos de 0 ou 1), o gradiente do MSE se aproxima de zero — a rede "trava" e para de aprender. A entropia cruzada (que vem da verossimilhança) não tem esse problema porque o logaritmo compensa a saturação da sigmoide.

Atenção — Não-convexidade

Ao contrário de modelos lineares, a função de custo de redes neurais profundas não é convexa — ela tem múltiplos vales locais. O SGD não garante encontrar o mínimo global. Na prática, isso não é um grande problema: os mínimos locais encontrados tendem a ter desempenho similar ao mínimo global.

Unidades de Saída — Saída Linear (Regressão)

saídaregressãoGaussiana

Quando a tarefa é prever um número contínuo (ex: temperatura, preço, duração), usamos saída linear com MSE.

ŷ = W⊤h + b Custo: J(θ) = (1/m) Σᵢ ||y⁽ⁱ⁾ - ŷ⁽ⁱ⁾||²
ŷ — predição (um número real ou vetor)
h — representação da última camada oculta
m — número de exemplos
MSE — minimizar MSE = maximizar verossimilhança Gaussiana

Unidades de Saída — Sigmoide (Classificação Binária)

saídaclassificação bináriasigmoideBernoulli

Quando a tarefa é responder sim/não (ex: "é spam?", "é gato?"), usamos sigmoide na saída + entropia cruzada binária.

P(y=1 | x) = σ(w⊤h + b) = 1 / (1 + exp(-z)) Custo: J = -[y log ŷ + (1-y) log(1-ŷ)]

Unidades de Saída — Softmax (Múltiplas Classes)

softmaxclassificação multiclassefórmulasaída

Quando a tarefa é classificar em N categorias (ex: dígito de 0 a 9, espécie de planta), usamos softmax — ela transforma N números em uma distribuição de probabilidade que soma 1.

Analogia — Votação com pesos

Imagine N candidatos com "pontuações" diferentes. Softmax é como converter pontuações em porcentagens de votos: eleva cada pontuação a eˢ (para garantir que sejam positivas) e depois divide cada uma pela soma total. Resultado: probabilidades que somam 100%.

softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ) Exemplo: z = [2, 1, 0.1] exp(z) = [7.39, 2.72, 1.10] soma = 11.21 softmax = [0.659, 0.242, 0.098] → soma = 1.0 ✓
zᵢ — pontuação bruta para a classe i (logit)
exp(zᵢ) — garante valores positivos
Σⱼ exp(zⱼ) — normaliza para somar 1
Problema de saturação do Softmax

Quando uma pontuação é muito maior que as outras (ex: z = [100, 1, 1]), a softmax satura e retorna probabilidades próximas de [1, 0, 0]. Nesse ponto, o gradiente praticamente desaparece. A solução é usar a versão numericamente estável: softmax(z − max(z)).

Redes de Mistura de Densidades (MDN)

MDNmultimodalsaída

Às vezes a relação x→y não é uma função simples — para um mesmo x, pode haver múltiplos y válidos (relação one-to-many). Uma MDN modela isso como uma mistura de Gaussianas: a rede aprende os pesos, médias e variâncias de cada componente da mistura.

Exemplo

Prever a posição de uma mão em um vídeo: para um frame igual, a mão pode estar em várias posições (o braço dobra para dois lados). Uma rede normal daria a média das duas posições (que pode não ser nenhuma delas). A MDN captura as duas possibilidades como duas Gaussianas separadas.

6.3

Unidades Ocultas — Funções de Ativação

ativaçãoReLUunidades ocultas

A função de ativação é o que dá não-linearidade à rede. Sem ela, empilhar camadas lineares seria equivalente a ter apenas uma camada linear. ReLU é a escolha padrão na maioria das arquiteturas modernas.

AtivaçãoFórmulaVantagemDesvantagemUso recomendado
ReLU max(0, z) Gradiente não satura, fácil de otimizar "Neurônio morto" se z sempre < 0 Padrão — use por default
Leaky ReLU max(αz, z), α=0.01 Sem neurônio morto α é hiperparâmetro Quando ReLU falha
PReLU max(αz, z), α aprendido α se adapta automaticamente Risco de overfitting Datasets grandes
Maxout max(w₁⊤x+b₁, w₂⊤x+b₂) Generaliza ReLU, muito expressivo 2x mais parâmetros por unidade Dropout
Sigmoide 1/(1+e⁻ᶻ) Saída probabilística (0,1) Satura, gradiente desaparece Só na saída (classif. binária)
Tanh (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ) Centrada no zero (−1,1) Ainda satura nas extremidades Melhor que sigmoide em ocultas
Problema do Gradiente Desvanescente

Sigmoide e tanh têm gradientes próximos de zero quando z é muito grande ou muito pequeno. Em redes profundas, multiplicar muitos gradientes pequenos (pela regra da cadeia) faz o gradiente da primeira camada se tornar microscopicamente pequeno — a rede para de aprender. ReLU resolve isso: para z > 0, o gradiente é sempre 1.

6.4

Design da Arquitetura

arquiteturaprofundidadelargura

Profundidade × Largura

Intuição — Hierarquia de conceitos

Por que profundidade (muitas camadas) é melhor que largura (muitas unidades numa única camada)? Pense em como humanos entendem linguagem: primeiro letras, depois sílabas, depois palavras, depois frases, depois contexto. Cada nível usa o nível anterior como base. Redes profundas aprendem hierarquias de conceitos da mesma forma — e isso é muito mais eficiente que tentar aprender tudo de uma vez numa camada gigante.

Exemplo concreto (Montufar et al., 2014)

Para representar certas funções com uma única camada oculta, a rede precisaria de um número exponencialmente maior de neurônios em comparação com uma rede de k camadas. Em termos práticos: uma rede com 3 camadas pode fazer com 100 neurônios o que uma rede de 1 camada precisaria de 10.000 para igualar.

Teorema da Aproximação Universal

teoremaaproximação universalprofundidade
O teorema (Hornik et al., 1989; Cybenko, 1989)

Uma rede feedforward com uma única camada oculta, um número finito de neurônios, e uma função de ativação "razoável" (não-polinomial) pode aproximar qualquer função contínua com precisão arbitrária.

O que o teorema NÃO diz

Ele não diz que é prático ou eficiente fazer isso com uma única camada. O número de neurônios necessários pode ser exponencialmente grande. E não diz nada sobre a facilidade de aprender (otimizar) essa rede.

É como dizer que qualquer livro pode ser escrito com 26 letras — tecnicamente verdade, mas não ajuda a escrever o livro.

6.5

Retropropagação (Backpropagation)

backpropgradientegrafos computacionais
Intuição — Atribuição de culpa

Quando a rede erra, quem tem culpa? O backprop é um algoritmo de atribuição de culpa: ele começa no erro final e vai rastreando para trás, calculando quanto cada peso contribuiu para o erro. Com essa informação, cada peso é ajustado proporcionalmente à sua culpa.

É como uma investigação de acidente: começa-se pelo resultado (o acidente), rastreia-se a cadeia de causas, e cada responsável recebe sua fração de culpa (gradiente).

Grafos Computacionais

Um grafo computacional é uma forma de representar qualquer cálculo matemático como um diagrama: os nós são operações ou variáveis, e as arestas indicam qual resultado alimenta qual operação.

A Regra da Cadeia

regra da cadeiaderivadagradientebackprop
Intuição — Efeito em cascata

Se mudar x afeta y, e mudar y afeta z, então quanto mudar x afeta z? É o produto das duas taxas de mudança. Esse princípio simples do cálculo — a regra da cadeia — é tudo o que o backprop usa. Aplicado milhares de vezes, de forma eficiente, ele calcula os gradientes de toda a rede.

Regra da cadeia (escalar): dz/dx = (dz/dy) · (dy/dx) Regra da cadeia (vetorial): ∂z/∂xᵢ = Σⱼ (∂z/∂yⱼ) · (∂yⱼ/∂xᵢ) ou em forma matricial: ∇ₓz = (∂y/∂x)⊤ · ∇ᵧz ↑ Jacobiana transposta
∂z/∂xᵢ — derivada parcial de z em relação ao i-ésimo elemento de x
∂yⱼ/∂xᵢ — Jacobiana: quanto o j-ésimo output de y muda com o i-ésimo input
∇ᵧz — gradiente de z em relação a y (vetor de derivadas parciais)
Exemplo numérico (com 2 números)

Seja y = 3x e z = y² . Queremos dz/dx.

dy/dx = 3  |  dz/dy = 2y

Pela cadeia: dz/dx = (2y) · 3 = 6y = 6(3x) = 18x

Para x=2: dz/dx = 36. Verificação: z = (3·2)² = 36, dz/dx = 18·2 = 36 ✓

O Algoritmo de Retropropagação

backpropalgoritmoforward passbackward pass

O backprop tem dois passos: forward (calcula a saída) e backward (calcula os gradientes de trás para frente).

Pseudocódigo — MLP com L camadas
FORWARD PASS:
  h⁽⁰⁾ = x                          (entrada)
  Para cada camada k = 1..L:
    a⁽ᵏ⁾ = W⁽ᵏ⁾ h⁽ᵏ⁻¹⁾ + b⁽ᵏ⁾      (pré-ativação)
    h⁽ᵏ⁾ = g(a⁽ᵏ⁾)                  (ativação, exceto na última)
  ŷ = h⁽ᴸ⁾
  J = L(ŷ, y)                        (calcula custo)

BACKWARD PASS:
  g⁽ᴸ⁾ = ∇_ŷ J                      (gradiente da saída)
  Para cada camada k = L..1:
    g⁽ᵃ⁾ = g⁽ᵏ⁾ ⊙ g'(a⁽ᵏ⁾)         (⊙ = produto elemento a elemento)
    ∇_W J = g⁽ᵃ⁾ h⁽ᵏ⁻¹⁾⊤            (gradiente dos pesos)
    ∇_b J = g⁽ᵃ⁾                     (gradiente dos vieses)
    g⁽ᵏ⁻¹⁾ = W⁽ᵏ⁾⊤ g⁽ᵃ⁾              (propaga gradiente para camada anterior)

ATUALIZAÇÃO:
  Para cada parâmetro θ:
    θ ← θ - α · ∇_θ J               (α = taxa de aprendizado)
Por que o backprop é eficiente?

Sem backprop, para calcular os gradientes de n parâmetros, precisaríamos de n passes pelo grafo computacional (um por parâmetro). Com backprop, um único pass para trás computa todos os gradientes simultaneamente. Isso é possível porque armazenamos os valores intermediários do forward pass e os reutilizamos — é uma forma de programação dinâmica.

Diferenciação Simbólica vs. Numérica

backpropautogradTheanoTensorFlowPyTorch
AbordagemO que fazExemplosVantagemDesvantagem
Symbol-to-number Computa numericamente o gradiente durante o forward pass Torch, Caffe, PyTorch (modo eager) Simples, intuitivo, suporta Python puro Não gera expressão simbólica do gradiente
Symbol-to-symbol Constrói um grafo novo que representa o próprio gradiente Theano, TensorFlow (graph mode) Gradientes de gradientes, otimização de compilação Mais complexo, grafo pode ser grande
Analogia

Symbol-to-number é como usar uma calculadora: você digita os números, ela calcula. Symbol-to-symbol é como álgebra simbólica: você escreve a fórmula em letras e o sistema simplifica e deriva a fórmula completa antes de calcular. PyTorch usa a primeira abordagem (mais intuitiva); o TensorFlow original usava a segunda (mais otimizável).

Derivadas de Ordem Superior

Hessianasegunda ordemKrylov

O backprop calcula gradientes (primeiras derivadas). Às vezes precisamos de derivadas de ordem superior, especialmente a Hessiana (matriz de segundas derivadas), útil para entender a curvatura da função de custo.

Por que a Hessiana é impraticável?

Para uma rede com n parâmetros, a Hessiana é uma matriz n×n. Com milhões de parâmetros, armazená-la seria impossível. A solução é usar produtos Hessiana-vetor (Hv), que podem ser calculados em O(n) sem montar a Hessiana completa — usando os chamados métodos de Krylov.

Três mudanças que salvaram as redes neurais

1. MSE → Entropia Cruzada: o MSE com sigmoide satura e trava o gradiente; entropia cruzada resolve isso.

2. Sigmoide → ReLU: ReLU não satura, gradiente não desaparece nas primeiras camadas.

3. Pré-treinamento → Inicialização aleatória (com boas práticas): hoje inicializamos pesos com distribuições bem calibradas (Xavier, He) e não precisamos mais de pré-treino não-supervisionado.
